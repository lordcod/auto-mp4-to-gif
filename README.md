### **Автоматическое преобразование MP4 в GIF**

Этот плагин автоматизирует процесс преобразования видео в формат GIF при добавлении MP4 файлов в папку. Это решение идеально подходит для пользователей, которые хотят быстро и без лишних усилий создавать GIF-анимированные изображения из видео.

---

### **Что делает этот плагин?**

Плагин мгновенно конвертирует ваше видео в GIF, как только оно попадает в папку, позволяя вам легко интегрировать анимации в документацию или проекты без необходимости вручную обрабатывать каждый файл.

---

### **Простой способ создавать документацию**

Плагин разработан специально для быстрой генерации анимаций в документации на GitBook, что ускоряет процесс добавления визуальных элементов в ваши проекты.

---

### **Требования**

Для корректной работы плагина требуется установленный **ffmpeg**. Это мощный инструмент для работы с мультимедийными файлами, который обеспечит быструю и качественную конвертацию.
